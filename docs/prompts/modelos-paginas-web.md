# Prompt: modelos de páginas web

Actúa como diseñador UX/UI y desarrollador web profesional.

Ya tengo una página web principal para mi emprendimiento de diseño y creación de páginas web. Quiero agregar dentro de esa página una sección para mostrar modelos o demostraciones de páginas dirigidas a diferentes tipos de negocios.

Voy a adjuntar los archivos de mi página actual. Analiza primero su diseño, estructura y tecnología. Después implementa la nueva sección respetando el estilo visual existente, sin eliminar ni dañar el contenido ni las funciones actuales.

OBJETIVO

Crear dentro de la página principal una sección llamada:

“Modelos de páginas web”

Esta sección debe permitir que los visitantes exploren diseños de ejemplo, seleccionen una categoría y accedan a la demostración completa de cada modelo.

ESTRUCTURA SOLICITADA

1. MENÚ PRINCIPAL

Agrega al menú de navegación un enlace llamado “Modelos”.

Al presionarlo, debe llevar a la sección de modelos de la página principal o a una página independiente llamada /modelos, según lo que sea más conveniente para la estructura actual.

2. SECCIÓN DE MODELOS EN LA PÁGINA PRINCIPAL

Crea una sección visualmente atractiva con:

Título:
“Encuentra un diseño para tu negocio”

Texto:
“Explora nuestros modelos, elige el estilo que más te guste y nosotros lo personalizamos con tu marca, contenido y necesidades.”

Muestra inicialmente entre tres y seis modelos destacados.

Cada modelo debe aparecer en una tarjeta con:

- Imagen o captura del diseño.
- Categoría del negocio.
- Nombre del modelo.
- Descripción breve.
- Funciones principales.
- Precio inicial opcional.
- Tiempo estimado de entrega opcional.
- Botón “Ver modelo”.
- Botón “Quiero este modelo”.

Incluye también un botón general llamado “Ver todos los modelos”.

3. CATEGORÍAS INICIALES

Crea ejemplos para estas categorías:

- Psicología.
- Joyería.
- Restaurante.
- Serviteca.
- Maquillaje.

El primer modelo de psicología puede llamarse “Espacio Sereno” y debe tener un estilo cálido, profesional y cercano.

4. ACCESO A LOS MODELOS

Cada botón “Ver modelo” debe abrir una demostración completa del diseño correspondiente.

Utiliza una estructura como esta:

- /modelos
- /modelos/psicologia
- /modelos/joyeria
- /modelos/restaurante
- /modelos/serviteca
- /modelos/maquillaje

Si la tecnología actual no utiliza rutas, crea páginas o archivos independientes equivalentes y enlázalos correctamente.

Cada demostración debe incluir una barra visible con:

“Este es un modelo demostrativo. Podemos personalizarlo para tu negocio.”

Y dos botones:

- “Quiero este modelo”.
- “Volver a todos los modelos”.

El botón “Quiero este modelo” debe llevar al formulario de contacto o abrir WhatsApp con un mensaje previamente escrito, por ejemplo:

“Hola, estoy interesado en el modelo Espacio Sereno de la categoría Psicología. Quiero recibir más información.”

5. SISTEMA PARA AGREGAR NUEVOS MODELOS

La estructura debe quedar preparada para agregar fácilmente modelos de nuevas categorías en el futuro.

Centraliza la información de los modelos en una sola estructura de datos, archivo o componente reutilizable. Cada modelo debe contener campos como:

- id
- nombre
- categoria
- slug
- descripcion
- imagen
- funciones
- precio
- tiempoEntrega
- enlaceDemostracion
- destacado
- mensajeWhatsApp

Cuando posteriormente solicite algo como:

“Agrega un modelo para una veterinaria”

debes:

- Crear la nueva categoría si todavía no existe.
- Crear la tarjeta del modelo.
- Agregarla a la sección de la página principal.
- Agregarla al catálogo general.
- Crear su página de demostración.
- Conectar correctamente todos los botones.
- Mantener el mismo sistema visual y técnico.
- No modificar ni eliminar los modelos anteriores.

6. CATÁLOGO COMPLETO

Crea una página o sección para ver todos los modelos.

Debe incluir:

- Filtro por categoría.
- Buscador por nombre o tipo de negocio.
- Diseño adaptable a celular, tableta y computador.
- Tarjetas consistentes.
- Mensaje claro cuando no existan resultados.
- Navegación sencilla hacia cada demostración.

7. DISEÑO

Mantén la identidad visual de mi página actual.

El resultado debe ser:

- Profesional.
- Moderno.
- Fácil de entender.
- Adaptable a dispositivos móviles.
- Rápido de cargar.
- Accesible.
- Visualmente coherente.
- Fácil de ampliar con nuevas categorías.

No uses testimonios, clientes, resultados ni estadísticas inventadas. Los modelos deben identificarse claramente como demostraciones.

8. FORMA DE TRABAJO

Antes de modificar el proyecto:

- Revisa todos los archivos adjuntos.
- Identifica la tecnología utilizada.
- Explica brevemente qué archivos vas a modificar o crear.
- Conserva una copia del código existente.
- No reemplaces el proyecto completo si puedes integrar la sección en la estructura actual.
- Reutiliza los componentes y estilos existentes cuando sea apropiado.
- No elimines contenido ni funcionalidades actuales.

Después:

- Implementa todos los cambios.
- Entrega el código completo de cada archivo modificado o creado.
- Indica exactamente dónde debe ubicarse cada archivo.
- Verifica que todos los enlaces y botones funcionen.
- Explica cómo agregar otro modelo posteriormente.
- Incluye instrucciones sencillas para probar el resultado.

Si falta un dato indispensable, hazme preguntas concretas antes de modificar el código. Si el dato no es indispensable, utiliza contenido demostrativo claramente identificado y continúa.
