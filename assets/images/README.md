# Recursos gráficos

Esta carpeta contiene las imágenes utilizadas por el sitio.

- `hero-ciberseguridad.png`: imagen principal de portada.
- `equipo-consultoria.png`: imagen del bloque de presentación.

Puede reemplazar cualquier archivo conservando su nombre para actualizar el sitio sin modificar el HTML. Para una nueva versión, agregue un archivo con otro nombre y cambie la ruta correspondiente en `fmv-infrasec.html`.

El logo está separado en `../brand/`. Reemplace `logo-temporal.svg` por el logo definitivo o actualice sus referencias en el HTML.
